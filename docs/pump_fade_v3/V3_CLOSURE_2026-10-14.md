2. **L4 (prediction), L4b and L5 (one-shot holdout evaluation) are not run.** L5 is defined for a selected rule or

   forward unchanged to the next research round.
4. Every arm evaluated in v3 counts toward the number of prior trials in any later multiple-testing correction.
