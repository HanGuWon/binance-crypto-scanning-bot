# Preregistered engineering amendment B (before historical outcome access)

Recorded 2026-10-07 KST, after implementing synthetic unit fixtures but **before reading any historical event outcomes**. Previous research policy A and its hash manifest are preserved as an immutable record; use `config/pump_fade_v2/policy_v2b.json` for all v2 experiments and release evaluations. Source policy ID changes from `prereg-a` to `prereg-b`; no prior efficacy campaign is reused.

1. **Funding state:** the literal interpretation of "cap touched during preceding 24h" would prevent R5 ever releasing before the 24-hour episode TTL after an on-event cap hit. We resolve this contradiction by allowing three chronologically observed normalized predicted-funding samples, spaced >=60s, to clear an earlier observed cap-hit WAIT. An observed interval *shortening* remains WAIT until a subsequent observed metadata snapshot restores the interval. Missing metadata remains unavailable.
2. **R3 post-treatment leakage:** declaring SKIP using the entire 24h post-event trajectory and then measuring a squeeze within those same 24h would select on the outcome. R3 association therefore uses a fixed 4h event-time landmark: record whether each joint SKIP condition was observed by 4h, then assess subsequent mark squeeze in the disjoint 4h–24h interval. Events without complete 4h evidence or 20h follow-up are censored. This does not establish the counterfactual impact of skipping.
3. **Causal peak/trough:** if a new 5m high and low occur in the same closed candle, their intrabar order is unknown. Reset the post-peak trough to that candle's known close; only later fully closed candles contribute new lows. The event candle's low cannot act as a known post-peak trough.
4. **Point-in-time baseline:** R1/R3 OI comparisons require an observed first post-event OI value no later than event +5min, rather than treating arbitrarily old snapshots as an event OI baseline. All required OI samples retain exchange event and local receipt timestamps.

The numeric thresholds, five hypotheses, original event definition, R1/R2 risk gates, nine R3 cells and 10,000 day-bootstrap specification are unchanged. Historical kline proxy diagnostics remain **development-only** until completeness and exposure eligibility are proven.
